# Getting Started

Rudel runs on a normal WordPress installation. It installs an early bootstrap into `wp-config.php`, creates host MySQL-backed runtime tables, and then resolves environments per request.

## Prerequisites

- WordPress 6.4 or later
- PHP 8.2 or later
- MySQL/MariaDB through the normal WordPress database connection
- permission to update `wp-config.php`

Multisite is not required.

## Install Rudel

### Via Composer

```bash
composer require rudel/rudel
wp plugin activate rudel
```

### Via zip

```bash
wp plugin install rudel.zip --activate
```

## Verify the runtime install

```bash
wp rudel status
```

That confirms the bootstrap and runtime tables are available.

## Create a sandbox

```bash
wp rudel create --name=alpha --theme=twentytwentyfour
```

That creates:

- a Rudel environment row
- cloned WordPress tables with a generated environment prefix
- a copied active theme inside the environment directory
- scoped metadata for snapshots, cleanup, Git, and lifecycle policy

Run WP-CLI against that environment:

```bash
RUDEL_ENVIRONMENT=alpha-1234 wp option get siteurl
```

Route an HTTP request to it:

```bash
curl -H 'X-Rudel-Environment: alpha-1234' http://localhost:8000/
```

## Create an app

Apps are durable overlays that can receive deploys and keep backups.

```bash
wp rudel app create --name=demo --domain=demo.example.test --theme=twentytwentyfour
```

Create a sandbox from that app:

```bash
wp rudel app create-sandbox demo-1234 --name=feature-a
```

Deploy the sandbox back into the app:

```bash
wp rudel app deploy demo-1234 feature-a-5678
```
